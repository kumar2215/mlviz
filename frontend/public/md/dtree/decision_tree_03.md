# Terminologies

The connections between nodes are called **branches**, which represent the possible answers to each question, such as yes or no. For example, in a game like _Guess Who?_, asking “Do they wear glasses?” would create two branches: **yes** and **no**. These branches lead to the next set of questions, which can be called **split nodes**, where you continue narrowing down the possibilities with new questions like “Do they have blonde hair?” or “Are they wearing a hat?” Eventually, you reach **leaf nodes**, which represent the final outcome—when you’ve narrowed it down to a single character and can confidently make your guess.
