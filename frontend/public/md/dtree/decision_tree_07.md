# Congratulations!

In this step, instead of letting the algorithm decide the splits, **you chose the questions yourself** and manually built the tree. In other words, you played the role of the decision tree algorithm.

Starting from the root, you selected a feature and a threshold to split the data—for example, a question like “Is petal length less than 2.5 cm?”. Each time you added a question, you divided the dataset into smaller groups and continued asking new questions to further separate the species. Eventually, each path ended with a final prediction.

This activity highlights what the algorithm normally does automatically: it searches through many possible questions and selects the ones that best separate the data. By building the tree manually, you can see how each question affects the dataset and how good questions quickly narrow down the possibilities—very similar to choosing effective questions in games like _20 Questions_ or _Guess Who?_.
