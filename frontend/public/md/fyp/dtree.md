# The Iris Dataset

To see decision trees in action, we can use the **Iris dataset**, one of the most well-known datasets in machine learning. It contains measurements of iris flowers and the goal is to classify each flower into one of three species: **setosa**, **versicolor**, or **virginica**.

Each flower in the dataset is described using four features: **sepal length**, **sepal width**, **petal length**, and **petal width**. A decision tree can learn a sequence of questions about these measurements—such as “Is the petal length less than 2.5 cm?”—to progressively narrow down which species the flower belongs to. By following these splits, the tree can classify a new flower based on its measurements.
