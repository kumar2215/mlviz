# Which pattern fits which text?

A pattern should preserve the boundaries your text needs.

| Preset | Best for |
| --- | --- |
| `\w+` / `\S+` | Words / non-space pieces. |
| Contractions | Apostrophes inside words. |
| Numbers | Signs and decimal points. |
| Social / email | Hashtags, mentions / addresses. |
| Hyphens / sentences | Compounds / sentence chunks. |
