The backend is responsible for all machine learning calculations and dataset management.

## Technology Stack
- **FastAPI**: The web framework.
- **Scikit-Learn**: The engine for all ML models.
- **Pydantic**: Data validation and settings management.
- **Numpy/Pandas**: Data manipulation.
