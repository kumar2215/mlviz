# Frontend Documentation (React)

The frontend is a React application that serves as the interactive visualization layer for MLviz.

## Key Sections

*   [**Visualizations**](visualisations.md) - How we render decision boundaries, trees, and plots using Recharts and D3.
*   [**Model Contexts**](contexts.md) - Deep dive into state management and capability interfaces.
*   [**Stories**](stories.md) - The graph-based navigation system for guided tours.
*   [**Extending the Frontend**](extending.md) - A guide for developers on how to add new visualization components or model types.

## Tech Stack
- **React**: Core library for UI.
- **Tailwind CSS**: Styling and layout.
- **Recharts / D3**: Visualization libraries.
- **Lucide React**: Iconography.
- **Framer Motion**: Smooth transitions and animations for stories.
